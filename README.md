# Адаптивное издание А. А. Вознесенского

Это адаптивное цифровое издание, которое подстраивается под интересы читателя. Вместо фиксированного оглавления мы предлагаем возможность самостоятельно выбирать, какие стихи Андрея Вознесенского читать — по их форме, сложности и тематике. В издание вошло 408 стихотворений. Их характеристики заранее подготовлены и хранятся вместе с текстами в `poems.json`.

## Возможности

- Фильтрация по метру стиха: классический и неклассический.
- Фильтрация по сложности: простой и сложный.
- Фильтрация по теме из списка.
- Выбор случайного стихотворения и последовательная навигация по результатам.
- Сброс фильтров
- Счётчик найденных стихотворений.
- Навигация клавишами со стрелками вперед по подборке и назад.

Фильтры можно сочетать. Повторное нажатие на активный фильтр снимает его.

Методики подсчёта метрик сложности, автоматического определения метра и темы доступны по сыслке: https://github.com/haertdinova/voznesenkylab_poetics

## Использование ИИ
Код сайта был сгенерирован ИИ (GPT-6 Luna). Результаты генерации были валидированы авторами проекта. В подготовке стихотворений к изданию и при создании фильтров ИИ не использовался.

## Файлы проекта

- `index.html` — основная страница издания.
- `about.html` — описание проекта.
- `script.js` — загрузка корпуса, фильтрация и навигация.
- `poems.json` — стихотворения и их характеристики (`id`, `title`, `verse`, `complexity`, `topic`, `text`).
- `topics.json` — список тем для фильтра.
- `header-art.png`, `footer.jpg` — изображения на основной странице.
